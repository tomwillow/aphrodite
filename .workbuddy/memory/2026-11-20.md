## 影片管理功能实现（grilling 两轮确认后定稿）

设计决策（用户逐条确认）：
- 目录配置：env `APHRODITE_FILM_DIRS`（逗号分隔容器路径，不用冒号避免 Windows 盘符冲突）
- 「打开」= 自定义协议 `aphrodite-play://`，点击时 1.5s 失焦启发式回退弹安装提示；
  处理器脚本内嵌 `films.py`，接口 `/api/films/handler` 供网页下载/复制
- 删除 = 真删磁盘（目录递归），确认弹窗把关；执行前校验文件仍在
- 扫描：进入哪级同步扫哪级 diff DB，不做全库扫描、无节流；文件夹拼贴=响应时只读 peek
- 日期口径统一用 mtime（Linux 容器拿不到真实创建时间）
- 目录树侧栏懒加载只含文件夹；视图切换 = 页内右上角下拉（按目录/按分类占位）
- 番号复用 codes.find_codes 取第一个，改名/不一致时重提；本轮不扩展 FC2 等格式
- 本项目(aphrodite)与 tutudu 无关，命名勿混淆

实现清单：
- backend: config.py 两个新 env；db.py film_dirs/film_entries 表 + 写函数（film_replace_level
  做 diff、film_delete_subtree 清后代）；films.py 新模块；app.py 五个 film 路由 + /film-media
- web: api.ts film 类型；FilmTree.vue / FilmCard.vue / LibraryView.vue 重写；vite proxy 加 /film-media

  common.sh 加 yml_film_host_dirs；aphrodite-play 脚本副本（环境限制放平在 scripts/ 下）

## deploy.sh / config_compose.sh 改为 .env 驱动（用户要求）

- 部署配置以项目根 `.env`（KEY=value，已入 .gitignore）为准，键：IMAGE / CONTAINER_NAME /
  BIND_ADDR / HOST_PORT / DATA_DIR / RESTART / TZ / JAVBUS_BASE / PAGE_INTERVAL /
  IMAGE_INTERVAL / TASK_WORKERS / IMAGE_WORKERS / MAX_ATTEMPTS / FILM_DIRS / FILM_PATH_MAP
- `deploy.sh` 默认全程静默（.env 缺失则警告+用默认值）；`-i` 走交互问答，答完回写 .env；
  `-y` 保留为兼容空操作。`config_compose.sh` 同逻辑（-i 交互并回写）
- `common.sh` 新增 `env_get / env_exists / env_write_back`（写回保留注释与未知键、原地更新已有键，
  ENV_FILE 可用 APHRODITE_ENV_FILE 覆盖）；默认值优先级 .env > 现有 compose > 内置默认
- 四个场景在临时目录实测通过：无 .env 静默生成、读 .env 生成 compose、反斜杠路径映射
  （Z:\Films）全程无损、交互回写保留注释/自定义键
- 坑：Git Bash 传参层会把 `Z:\Films` 这类 Windows 路径参数转成 `Z:/Films`（MSYS 路径转换），
  测试含反斜杠的值要用变量拼接绕开；脚本本身无此问题
- AGENTS.md 部署段已同步更新
