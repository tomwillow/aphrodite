- 硬性约定提炼自现有代码里容易被破坏的不变量：
  1. `backend/codes.py` 与 `web/src/lib/codes.ts` 解析规则镜像，后端为准，改动要双端同步 + 双端测试；
  2. 一切状态变更必须走 `db.set_*/touch_task`（自带 `next_rev()`），直连 SQL 会让 SSE 推不出去；删行要写 `removals` 墓碑；
  3. 写操作走 `_write_lock` + 线程本地 `conn()`；
  4. 联网返回后必须二次校验 `db.get_item` / `is_item_cancelled`，防「删完又写回」；
  5. 图片路径存相对 `IMAGES_DIR` 的 posix 路径，删除任务不删图库文件；
  6. 重试只在 worker（`crawler.download` 单次尝试 + `attempts` 记账）；
  7. 占位图靠 md5 去重 + 自学习黑名单，不许退化成 URL 启发式；
  8. 不引新依赖 / UI 框架；
  9. 状态常量是前后端契约，改一处要改五处（db.py、worker/app、api.ts、status.ts、测试）；
  10. 文案中文。
