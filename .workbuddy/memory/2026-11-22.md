## 单视频目录就地改名，不再套一层（14:30）
- 需求：`wandoujia/LTX/OFJE-041-LTX` 这类目录里只有一个视频且番号与目录名一致时，
  应把该目录本身改名成 `[番号][演员][标题]`，而不是在它下面再建一层标准目录。
- 实现（filmtools）：
  - `_flat_dir(root, video, code)`：从视频所在目录向上，逐级判定「不是影片根 + 目录名里
    有该番号 + 子树里带番号的视频只有 1 个」，取最外层命中者作为 cand → 就地改名。
    因为向上取最外层，旧版造出的「目录/标准目录/视频」会被拍平。
  - `_dir_coded_video_count`：只数**带番号**的视频（广告片不挡判定）；`_dir_code_matches`
    用 `find_codes(目录名)` 与视频番号比对（`OFJE-041-LTX` → `OFJE-041`）。
  - `_organize_flat(item, root, video, code, cand)` 取代原 `_verify_organized`：改名（目标名
    被占用则保留原名、不拍平，避免把视频提出标准目录；OSError 不判失败）→ `_pull_up`
    把内层文件提上来并删空壳目录 → `_ensure_cover(overwrite=False)` / `_ensure_samples`。
    全合格 skipped、有改动 done，target 写新目录 rel。
  - `_organize_one`：cand 命中 → `_organize_flat`；否则 parent 是标准目录 → skipped；
    其余仍走「建标准子目录再搬」的旧路径。**影片根目录永不改名**。
  - 顺手修取消抖动：`_process_all` 循环结束后再查一次 cancelled（单条目任务取消曾变成 completed）。
- 测试：后端 87 全绿（filmtools 23：新增就地改名 / 拍平旧套娃 / 根目录不改名 /
  多视频不就地改名 / 混广告片仍改名）。
- 真机验证：`LTX/OFJE-041-LTX` → 拍平成 `LTX/[OFJE-041][...]`（外层目录消失、内层套娃
  拍平、封面与视频同名、详图 s2–s11 齐全，再跑 skipped）；`LTX/SNIS-557-UC`（含 2 个
  无番号广告片）也成功就地改名，封面改成与视频同名。库中 SNIS-557 的 samples 全是
