# 2026-11-03

## 新项目：Aphrodite（番号图集爬取工具）

从零搭建完成，位于 D:/code/aphrodite。

**技术栈**：FastAPI + SQLite(WAL) + requests/bs4 后端；Vite + Vue3 + TS 前端（无 UI 框架，自写样式）。前端构建产物由后端托管（`web/dist`），单端口 8000。

**架构要点**：
- `backend/codes.py`：番号解析 `[A-Za-z]{2,6}[-全角破折号]\d{2,6}`，前端 `web/src/lib/codes.ts` 同规则镜像（前端仅预览，后端为准）。
- `backend/crawler.py`：JavBus 搜索（`a.movie-box` + `<date>` 匹配番号）→ 详情页（`a.bigImage` 主图 + `a.sample-box` 详情图）→ 图片下载。页面请求全局限速 1.2s，图片 0.15s；404=未找到，Age Verification 页自动重试。
- `backend/worker.py`：ThreadPoolExecutor（2 任务并发），番号内图片 5 并发下载（跨境单张 3-4s，串行太慢）。每行带全局递增 rev。
- 实时推送：SSE `/api/tasks/{id}/stream?rev=N`，按 rev 增量拉 SQLite diff（400ms 轮询式推送，简单可靠），事件 task/items/images/done。
- 图片存 `data/images/{task_id}/{code}/cover.jpg | sample-NN.jpg`，经 `/media` 静态服务。重启自动 resume 未完成任务（已下载文件按文件名复用）。
- 占位图处理：dmm 对不存在的详情图返回同一张 NOW PRINTING 图。方案=番号内内容 md5 去重 + 自学习黑名单 `data/placeholder_hashes.txt`（发现重复即记录哈希，后续任务直接 skip，status='skipped' 前端隐藏）。

**已验证**：真实任务（IPX-528/AVOP-201/MIDE-100/IPX-439/XXX-999）全流程跑通；Chrome headless 截图确认三个页面 UI 正常。

**运行**：`./.venv/Scripts/python.exe run.py`（后端依赖已装于 .venv）；前端改动需 `cd web && npm run build`，开发模式 `npm run dev`（proxy 到 8000）。

**已知限制**：番号首次遇到新型占位图时该图会显示一次，第二个任务起自动跳过。

## 功能迭代（11-04 晚）：统一图库 + 删除任务 + 失败重试
- **统一图库**：下载落盘位置从 `data/images/{task_id}/{code}/` 改为 `data/images/library/{code}/`；新增 `library` / `library_images` 两张表按番号索引，新任务遇到已下载番号直接建行复用（实测 3 秒完成、零联网，item.cached=1 前端显示"图库复用"）。图库里失败过的图会重新排队而不是被丢弃。
- **历史数据迁移**：`db.migrate_files_to_library()` 每次启动按文件系统扫描 `data/images/{数字目录}/{番号}/` → 移动到 library 并改写两表 path，顺带清理空目录。已迁移 139+ 个文件，旧目录清空。
- **删除任务**：`DELETE /api/tasks/{id}` → `runner.cancel()` 打标记，执行线程在检查点退出（取消中的下载不落库），finally 里再 `db.delete_task` 清残留；图库文件不删（属于共享缓存）。列表页 hover 显示删除按钮。
- **下载重试**：`crawler.download` 改为单次尝试，重试上移到 worker（5 次、递增退避 1.2s×n、`images.attempts` 记录次数，前端显示"已试 N 次"）。`POST /api/tasks/{id}/retry` 把 failed 图片重置为 pending、attempts=0、item 回 pending，并重新入队；也用于恢复被中断的任务（unfinished 计数）。
- 测试增至后端 24 + 前端 17 全绿（新增 library 复用/重试/删除/attempts 用例）。
- 踩坑记录：Windows 下 `python xxx.py &` 起服务会在 shell 结束时被杀，必须用 run_in_background。
